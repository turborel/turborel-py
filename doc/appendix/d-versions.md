# Appendix D: Versions

[Contents](README.md)

The driver's version is the number of the turborel release it is made
for, the same as the server's. This is version 0.0.0, the alpha, made
for turborel 0.0.0, and it speaks the native protocol's version 1, the
only version. Until 1.0.0 anything the manual describes may change in
any release.
